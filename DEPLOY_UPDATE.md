# Update Existing Azure Static Web App

1. Extract this ZIP.
2. Open your existing GitHub repository folder in VS Code.
3. Copy all extracted files into the repository root and replace old files.
4. Run:

```powershell
git add .
git commit -m "Update portfolio-themed internship presentation"
git push
```

5. Open GitHub Actions and wait for the Azure Static Web Apps deployment to show a green check.
6. Refresh your Azure URL.


Update included: borderless slide stage, theme switcher (Cyber/Ocean/Bright/Sunset), floating code/webpage background elements, and responsive first-slide sizing. Press `T` to cycle themes.
