About Systems Limited

Systems Limited is a leading Pakistani global technology company with a long history in digital transformation and enterprise technology services.

  • Provides digital strategy, business applications, cloud, data & analytics, AI, digital commerce and business process services.
  • Serves clients across international markets through onsite and offshore delivery models.
  • Works with industry verticals such as banking, retail, public sector, communications and health.

My Front-End Workflow

From Requirement to Responsive Page

01Understand

Read requirement and identify page sections.

02Structure

Create semantic HTML and organize content.

03Style

Apply CSS spacing, colors, layout and consistency.

04Adapt

Make the layout responsive for mobile and laptop screens.

05Test

Review output, debug issues and refine final presentation.

Core Learning 01

HTML: Building the Structure

  • Created complete page skeletons using head, body, header, section and footer.
  • Practiced headings, paragraphs, links, images, lists, tables and forms.
  • Learned clean file paths for CSS, JavaScript and images.
  • Improved semantic structure so pages were easier to style and maintain.
<header>
  <nav>Home · About · Contact</nav>
</header>
<main>
  <section class="hero">
    <h1>Front-End Project</h1>
  </section>
</main>

Core Learning 02

CSS: Design, Layout & Responsiveness

  • Used selectors, colors, fonts, spacing, borders and backgrounds.
  • Practiced box model, margin, padding and element sizing.
  • Used Flexbox and Grid for layout alignment and structure.
  • Applied media queries to make pages mobile-friendly.

Core Learning 03

Basic JavaScript Interaction

DOM SelectionquerySelector()

Connected JavaScript with HTML elements.

Eventsclick / input

Triggered simple actions from user interaction.

Logicif / else

Handled simple decisions and form checks.

FunctionsReusable code

Organized small tasks into clear functions.

JavaScript was intentionally kept at basic level because the main internship focus was HTML and CSS.

Practice Project

Mini Front-End Project Work

I practiced creating a small front-end interface using HTML, CSS and JavaScript. The screen shown here represents project-style learning, where structure, styling and small JavaScript behavior were combined in one working page.

Example: GitHub Profile Viewer style interface with input field, profile button and dynamic profile details.

Digital Workplace Exposure

Understanding Internal Systems

The internship also gave exposure to how a professional technology company uses internal systems, attendance tools and digital communication. This helped me understand how software supports real organizational processes.

  • Observed structured check-in and check-out workflows.
  • Understood the role of digital tools in office discipline.
  • Connected front-end interface design with real user needs.

Professional Culture

Communication, Events & Team Environment

The office environment showed how technical learning, professional communication and organizational culture work together.

JavaScript BasicsPracticed DOM selection, events and small functions.
